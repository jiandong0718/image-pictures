# 管理员服务中心

入口为 `/service-center`，导航位于“管理”分组，仅管理员可访问。原充值管理保留。

## 页面

- 今日概览：当前用户总数、今日新增、今日活跃、图片张数、视频条数、语音条数、消耗积分、提交任务数。
- 每日趋势：近 7 天、近 30 天、自定义日期（最多 366 天），支持六个指标切换与每日数据表。
- 服务使用：按入口查看提交、完整成功、部分成功、失败、进行中、中断、成功率和产出数量，可进入任务明细。
- 用户明细：用户名搜索与分页，展示注册时间、最近活跃、所选期间各类生成量、消耗和当前余额，可查看该用户的任务。
- 页面默认包含管理员，可取消勾选；所有区域使用相同角色范围。日期只影响趋势与明细，顶部始终为今日数据。
- 服务使用包含提示词提取；该服务没有图片、视频或语音产出，统计提交、成功和失败次数。

## 口径

所有日期按北京时间零点划分。新增用户和积分消费来自已有记录，使用 MySQL `UNIX_TIMESTAMP` 把原数据库会话时间转换成时间戳，再按北京时间聚合；新统计记录使用毫秒时间戳和明确的北京时间日期。

活跃指已登录用户实际访问页面、读取常用业务列表或执行写操作，按账号和日期去重。保持登录后访问也记录；任务后台轮询、媒体文件和静态资源请求不产生新活跃。同一用户一分钟内合并写入，跨日立即写入。最近活跃可能有一分钟内的记录间隔。

任务按提交日统计，产出按完成日统计。因此同一日期的提交量不必等于产出数量。一次批量请求算一个任务，生成四张图算四张产出。完整成功率 = 完整成功任务 /（完整成功 + 部分成功 + 失败）；运行中和中断不放入分母。

已生成但随后失败的部分输出仍计入产出。已保存、等待核对结算的音视频也可按已知输出记录产出，任务状态仍保持中断。统计记录在原业务事务之外执行，失败只记录统计异常，不改变已有任务结果、不再次扣费。

## 存储与历史范围

启动时幂等创建四张独立表，不改动原业务表：

| 表 | 内容 |
| --- | --- |
| `service_metrics_meta` | 活跃记录启用时间、历史作品回填标记 |
| `service_user_activity` | 用户按日活跃与最近访问时间 |
| `service_tasks` | 不含提示词、错误正文或凭据的任务摘要 |
| `service_outputs` | 按媒体类型及资源 ID 去重的产出账本 |

启动时先回填已有生成任务，再补入已有图片与视频索引；图库历史文件扫描完成后再同步一次统计。主键去重，重复回填不重复累计；上传主图排除。语音从生成任务的已知结果回填，不把上传音频当作生成。无法确认历史入口的图片标为“生图（入口未知）”，有可靠任务记录时修正入口。旧版提示词提取仅能根据成功扣费流水回填成功次数，历史失败次数无法还原；新请求记录成功与失败。

历史活跃没有可核实来源，不补造；启用前显示“未记录”，首日注明仅覆盖启用后的时段。已删除且没有可核实记录的旧产出无法还原。旧同步代理没有任务和作品记录的请求也无法从积分反推生成量。新增同步代理请求会登记任务与产出。

统计表不级联删除媒体或账号，已登记的产出不会随着作品删除而减少。管理员筛选优先采用当前用户角色；账号已删除时使用统计记录中的角色。新生图入口从请求来源页面确定，并把分类存入任务；无法确定的调用保留未知分类。

## 接口

- `GET /api/service-center/dashboard`
- `GET /api/service-center/users`
- `GET /api/service-center/tasks`

公共参数：`start`、`end`（YYYY-MM-DD）、`includeAdmins`（接口默认 false，页面默认传 true）。用户明细增加 `keyword/page/pageSize`；任务明细增加 `module/userId/page/pageSize`。分页复用 10/20/50 条规则。接口未登录返回 401，普通用户返回 403；不返回任务输入、生成提示词、接口地址、Key、用户联系方式。

## 验证

```bash
cd image-design-workbench
npm test
node tests/service-center-mysql.js
```

第二个命令仅允许连接本机 MySQL，会创建 `service_center_test_*` 临时数据库和独立临时输出目录，退出时清理。图片与语音使用本机模拟上游，不调用真实付费模型。增加 `--serve` 可保留隔离页面用于浏览器检查，Ctrl+C 清理。

隔离验收覆盖真实 SQL 聚合、北京时间跨日、部分成功、回填去重、上传排除、角色筛选、活跃去重、权限、分页、删除作品保留统计，以及实际图片、同步代理和语音任务的统计记录与原积分结算。
