# 模块节点与模型检查（2026-10-29）

## 本次核对与修改

节点是配置中心的生图服务（image_endpoints），名称取管理员填写的 label。只展示启用节点；未命名时使用带数据库 ID 的稳定提示。模型列表随节点切换，默认选择该节点配置的默认模型；不会展示其他节点的模型。切换节点时重置模型，服务端再次校验模型归属。

## 全局默认与自定义选择

- 配置中心的服务更多菜单支持「设为全局默认」，将启用节点的 ID 持久化到 app_settings.image_default_endpoint_id；默认模型始终取该节点当前配置的默认模型。
- 优先级：模块内显式节点/模型 > 全局默认节点/默认模型 > 未设或默认节点停用、删除时的调度策略。上游调用失败不等于节点被停用。
- 所有八个生图模块的节点下拉框包含「全局默认 · 节点名称」。此时模型只读，提交空节点/模型，由服务端在提交时解析默认；显式选择节点后才允许选择该节点的模型。
- 自定义选择可以保留，也可以切回全局默认。已删除/停用的自定义节点会回到跟随全局。切换设置不会擅自创建模型调用。
- 绘图聚集地继承全局时，其代理请求保留空模型；服务端对 JSON 和 multipart 请求补入实际默认模型，图片二进制不变。
- 隔离浏览器验证：8 个入口均通过「切换自定义节点 → 只显示该节点模型 → 切回全局」；后端测试覆盖默认持久化、显式覆盖、默认模型更新和停用回退。

## 配置与服务端检查

- 修复配置中心保存时只保留默认模型的问题；保存会保留节点拉取的目录，默认模型排首位。
- 绘图聚集地指定节点后重试仍使用该节点。内部路由字段不向上游传递，multipart 图片字节保持完整。
- 不把单组的视频、语音、视觉理解配置当成生图端点池；这些模块若要多节点，需要扩展各自存储与协议。

## 验证边界

- 用同一套真实前端文件搭建隔离示例 API，逐页验证上述 8 个生图入口的下拉框、节点名称及模型联动。
- 示例节点 1：agens 主节点，模型 gpt-image-2.5 / gpt-image-2；示例节点 2：备用专用节点，仅 image-b。
- 自由生图示例提交记录为 endpointId=2、model=image-b；绘图聚集地示例提交记录为 endpoint_id=2、model=image-b。
- 示例 API 不返回生成图片，因此仅确认提交与路由参数，不把模拟任务终态作为真实生图成功证据。
- 自动化覆盖模型不匹配、删除/停用节点、节点名称投影、默认模型回退、代理字段清理及二进制保真。
- 不访问真实模型接口，不产生真实模型费用。历史节点若目录只保存了一个模型，需要在配置中心重新拉取并保存。

## 创作界面调整

- 音频生成页移除服务配置表单和配置写接口调用；管理员从「服务设置」直达配置中心的语音生成分类。音频页只保留文本、声音参数、费用与作品。
- 自由生图在桌面端左侧展示作品，右侧统一放置文生图/图生图切换、参考图上传、提示词及生成参数；右侧参数可独立滚动，生成入口保持可见。
- 创作工作台与四个套图工作台将节点/模型控件收进右上角抽屉。未自定义时跟随全局；抽屉内可恢复默认。
- 绘图聚集地恢复底部尺寸、质量、格式、压缩率、审核、背景、数量，节点/模型也放入同一区域，保留每页记录数与任务分页。
- 当前异步代理没有实时流式预览能力，「生成预览」显示暂不支持；背景的透明选项标明使用现有本地处理机制。
- 隔离请求验证：底部选择的 endpoint_id=2、model=image-b、quality=low、output_format=jpeg、output_compression=80、n=2 均进入生成请求。
- 桌面与 390px 窄屏检查均无页面横向溢出。浏览器截图为示例数据，不代表真实上游生成成功。
