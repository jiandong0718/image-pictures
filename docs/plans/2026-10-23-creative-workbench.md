## 实施与验收

- [x] 图片性能：真实大图对比；WebP、原子落盘、同图并发合并及缓存失效；列表统一预览，详情/下载保持原件；媒体流式与条件请求；首页追加分页不重建已有卡片。
- [x] 任务与结算：持久化任务状态、部分结果和参数；旧业务保持成功后扣费，兼容层写库失败不改变已知结果；新音频独立预占和幂等结算；未知结果不自动重新生成。
- [x] 创作资源服务：私有提示词、七个外部标准 JSON 来源、检索收藏；素材上传/标签/收藏/删除及图库引用；文本/图片引用编排；受保护媒体 API。
- [x] 独立创作工作台：图片创作与原视频/新音频入口、提示词素材选择、按用户保存草稿与方案、批次记录、多参考图；单图参数保持兼容。
- [x] 音频：独立管理员配置；声音/格式/语速/指令；按用户确认的字符长度收费；中断核对、幂等退款/结算；真实模型调用未执行。
- [x] 验证：58 项基线通过；新增离线回归；真实本机隔离 MySQL + 模拟模型端到端；浏览器主要流程；性能数据与线上未验证边界已记录。

边界：本轮在隔离工作区开发；不自动发布到生产。用户已明确音频按文字长度收费，管理员可配置字符档位及单价。新数据表仅在隔离测试库验证。旧业务价格、参数、页面和流程不调整，不接入旧业务预占。

责任分工：主智能体负责性能与 server.js 集成；独立任务分别负责持久任务/积分模块、创作资源后端模块、创作资源前端页面，避免交叉修改文件。
